=============================================================
 ARCHITECTURE NOTES
=============================================================

• Circular dependencies broken via dependency injection:
  - TitleMenu receives audioManager, gameManager, dataManager via constructor
  - TownScreen receives 13 dependencies via constructor
  - No class stores `this.game` anymore

• EventBus is the central communication hub:
  - ~45 emit() calls across all files
  - ~41 on() listeners across all files

• Data-driven design:
  - Adding new weapon = edit embeddedData.js
  - Adding new NPC = edit npcData.js
  - Adding new location = edit locationTree.js
  - Adding new companion = edit companionData.js

• 34 legacy engine files exist in engine/ but are NOT loaded
  (individual class files from earlier extraction phases)
